Panduan Sortir Gudang

1Cara Membaca Kode Paket

Setiap paket memiliki awalan kode yang harus dicocokkan dengan rak tujuan.

A-123 → Rak A

B-456 → Rak B

C-789 → Rak C

EXP-99 → Express

FRG-02 → Fragile

RET-88 → Return

2Metode Kontrol

  • Desktop: Seret paket ke rak tujuan.
  • Mobile: Ketuk rak tujuan langsung; tidak perlu memilih paket dulu.
  • Keyboard: Tekan angka 1 sampai 6. Tekan P untuk pause/resume.

3Combo & Waktu

Jawaban benar beruntun menaikkan combo dan skor. Timeout atau salah sortir memutus combo.
