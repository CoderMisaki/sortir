Panduan Sortir Gudang

1 Cara Membaca Kode Paket

Setiap paket memiliki label unik dengan kode prefix. Perhatikan awalan huruf kodenya untuk mencocokkan dengan tujuannya:

A-123 → Rak A
B-456 → Rak B
C-789 → Rak C
EXP-99 → Express
FRG-02 → Fragile
RET-88 → Return

2 Metode Kontrol (Multi-cara)

  • Desktop Drag & Drop: Seret paket dari ban berjalan dan letakkan langsung pada Rak tujuan.
  • Klik/Sentuh langsung: Klik/Ketuk paket untuk memilihnya, lalu klik Rak yang benar (Sangat nyaman untuk HP).
  • Shortcut Keyboard: Tekan angka 1 sampai 6 untuk menyortir super kilat!

3 Sistem Combo & Waktu

Semakin cepat dan berurutan Anda berhasil menyortir tanpa salah, Combo akan berlipat ganda dan melipatgandakan perolehan poin Anda! Namun, hati-hati dengan penalti jika waktu habis.
